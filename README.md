# System Monitoring Script

## Overview
This script monitors:

- Disk Usage
- Memory Usage
- Top CPU Processes
- Top Memory Processes

## Thresholds

Disk Threshold: 80%
Memory Threshold: 80%

## Run Script

```bash
./system_monitor.sh

## Sample Output

Run:

./system_monitor.sh

The script will display:

- Disk Usage Percentage
- Memory Usage Percentage
- Top 5 CPU Consuming Processes
- Top 5 Memory Consuming Processes
- Alert Messages (if thresholds are exceeded)
